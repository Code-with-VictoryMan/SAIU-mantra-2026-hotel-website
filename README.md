# MANTRA 2026 Sample Hotel Website

This is a beginner-friendly sample frontend website for the MANTRA 2026 Summer School assignment.

## Website Type
Hotel Website (Royal Obsidian Rooms)

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub
- Netlify

## Pages Included
- Home
- About
- Rooms
- Gallery
- Contact

## Features
- Responsive design for mobile, tablet and desktop
- SEO tags on every page
- Image alt text
- Mobile navigation menu
- Booking form validation using JavaScript
- Scroll reveal animations using JavaScript IntersectionObserver
- Custom cinematic dark theme using CSS Flexbox and Grid

## How to Run
Open `index.html` in any browser.

## Netlify Deployment Steps
1. Create a GitHub repository.
2. Upload all files from this folder.
3. Login to Netlify.
4. Click "Add new site" > "Import an existing project".
5. Connect GitHub repository.
6. Deploy the website.
